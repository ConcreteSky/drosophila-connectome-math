Abstract

This report evaluates whether the complete synaptic wiring diagram of an adult Drosophila melanogaster brain can operate as a biological computing substrate for discrete working-memory logic and arithmetic when trained exclusively with scalar reward (+1) and punishment (−1) feedback. We ingest the FlyWire v783 whole-brain connectome (138,639 proofread neurons, 15,091,983 directed edges, and 54,492,922 weighted synapses) into DuckDB and Parquet, compile it into a Dale's-Law-compliant Compressed Sparse Row (CSR) PyTorch representation, and simulate batched Leaky Integrate-and-Fire (LIF) dynamics across local CPU and GPU backends. At batch size 1, sparse GPU execution achieves a 12.1× speedup over CPU (129.40 ms versus 1572.10 ms per 60 ms trial) within a 330.08 MB memory footprint. Under three-factor dopamine-modulated Reward-STDP (R-STDP) and spiking REINFORCE baselines, the connectome reaches 70.0% held-out accuracy on delayed_xor (versus 40.0% for a matched PyTorch GRU) and exhibits functional collapse (0.0%) followed by plastic recovery (100.0%) under Central Complex ablation. Scaling the evaluation to bit-coded 0–100 arithmetic with strict train/test isolation (800 sampled training pairs, 200 unseen test pairs) establishes a clear empirical boundary: while unseen per-bit accuracy rises well above chance (62.8% for addition, 67.3% for subtraction), exact 9-bit integer generalization remains low (1.0%–2.5%), demonstrating that a biological spiking reservoir with a single plastic readout cannot substitute for multi-layer carry-propagation circuits.

Keywords: Drosophila connectome, FlyWire v783, spiking neural networks, Leaky Integrate-and-Fire, three-factor R-STDP, Dale's Law, lesion ablation, serverless deployment.

1. Introduction

Standard artificial neural networks rely on dense, homogeneous weight matrices optimized by global error backpropagation. Biological nervous systems operate under fundamentally different constraints: sparse, heterogeneous directed graphs shaped by evolution, strict neurotransmitter sign constraints (Dale's Law), discrete spike-time signaling, and local synaptic plasticity modulated by scalar neuromodulatory signals such as dopamine. With the public release of the FlyWire v783 whole-brain connectome of adult Drosophila melanogaster (Dorkenwald et al., 2024; Shiu et al., 2024), it is now possible to instantiate every proofread neuron and synaptic connection of an entire adult insect brain in simulation.

Rather than treating the connectome solely as a static graph or building a digital calculator wrapped in biological graphics, this project tests a concrete empirical hypothesis: to what extent can a real insect connectome learn working-memory logic and discrete arithmetic solely through biologically plausible reward (+1) and punishment (−1) plasticity? Answering this question honestly requires separating genuine spiking computation from memorization, hyperparameter overfitting, and software shortcuts.

To enforce scientific discipline throughout the codebase, the system obeys three explicit architectural boundaries:

  1. No Hardcoded Arithmetic Shortcuts: Every prediction is decoded exclusively from competing Motor/Output population spikes and Mushroom Body Kenyon-cell projections. When the connectome fails to generalize on unseen operands, the system reports the failure directly.
  2. Strict Train/Test Isolation: All arithmetic and logic evaluations measure performance on held-out operand pairs excluded from training, preventing lookup-table memorization from being reported as algorithmic learning.
  3. Structural and Algorithmic Controls: Real connectome runs are benchmarked against a degree-preserving configuration-model shuffled brain and a matched-budget non-spiking PyTorch GRU trained under identical 60 ms temporal schedules.

The complete engineering pipeline comprises five layers: (i) reproducible DuckDB/Parquet ingestion of FlyWire v783, (ii) a batched sparse CSR LIF simulator with spike-frequency adaptation and Dale's Law enforcement, (iii) dual plasticity engines (three-factor R-STDP and spiking REINFORCE) with state-dependent error avoidance, (iv) targeted regional and top-5% out-degree hub lesion ablations, and (v) a same-origin Vercel web application pairing a pure-NumPy FastAPI serverless backend with a 60 FPS anatomical Canvas interface.

2. Connectome Dataset and Anatomical Partitioning

The structural wiring graph is compiled in scripts/download_connectome.py and src/flybrain_rl/connectome.py from three FlyWire v783 release files: Completeness_783.csv (the proofread neuron registry), Connectivity_783.parquet (directed presynaptic-to-postsynaptic synapse counts), and Supplemental_file1_neuron_annotations.tsv (anatomical super-class, cell-class, cell-type, and neurotransmitter polarity). Using deterministic DuckDB SQL queries over the Parquet tables, each proofread neuron is mapped to a contiguous zero-based integer index 0..138,638, and each directed edge is weighted by its signed synapse count (Excitatory × Connectivity).

The resulting whole-brain graph contains 138,639 proofread neurons, 15,091,983 directed CSR edges, and 54,492,922 total weighted synapses. Compiling these arrays into PyTorch CSR format produces a reusable 123.2 MB binary checkpoint (data/connectome_csr_v2.pt), eliminating repeated Parquet joins during training and benchmarking.

4. Biophysical Model and Plasticity Rules

4.1 Batched Leaky Integrate-and-Fire Dynamics with Adaptation

In SpikingFlyBrain (src/flybrain_rl/brain.py), neural activity is integrated at discrete time step Δt = 1.0 ms over a T = 60 ms trial horizon for batch size B. Compiled connectome weights are scaled by weight_scale = 2.0. At each step t, synaptic currents Isyn(t) decay exponentially with time constant τsyn = 5.0 ms (β = exp(−Δt/τsyn)) while receiving presynaptic spikes through the transposed CSR matrix WT and external sensory currents Iext(t):

Isyn(t) = β Isyn(t − 1) + WT s(t − 1) + Iext(t)
(1)

Membrane potentials V(t) integrate toward resting potential Vrest = −52.0 mV with membrane time constant τm = 20.0 ms (α = exp(−Δt/τm)) and resistance Rm = 1.0. To prevent runaway synchronous bursting in high-degree interneurons, each neuron maintains an adaptive threshold offset θadapt(t) decaying with τadapt = 40.0 ms (γadapt = exp(−Δt/τadapt)) and incrementing by 0.4 mV upon each spike:

V(t) = α V(t − 1) + (1 − α)(Vrest + Rm Isyn(t))
(2)
s(t) = 1[V(t) ≥ Vthresh + θadapt(t) ∧ refrac(t) = 0],    θadapt(t + 1) = γadapt θadapt(t) + 0.4 s(t)
(3)

Neurons that cross threshold (Vthresh = −45.0 mV) reset immediately to Vreset = −52.0 mV and enter a 2 ms refractory period. A binary vector active_mask clamps lesioned neurons at Vrest and zeroes their spike output without altering the underlying CSR indices.

4.2 Dual-Rail Population Spike Encoding and Trial Timing

In PopulationEncoderDecoder (src/flybrain_rl/encoding.py), non-overlapping sensory pools of up to 64 neurons are assigned per input channel. For bit-coded 0–100 arithmetic, each 7-bit operand is represented by 14 dual-rail channels (explicit pools for both bit = 1 and bit = 0), maintaining constant total sensory drive independent of operand Hamming weight. Active channels inject Bernoulli spike currents with probability rate_prob = 0.80 and amplitude drive_amp = 55.0. A dedicated go_pool fires during the readout window at probability 0.70 (amplitude 0.85 × drive_amp).

  • Working-Memory Schedule (delayed_xor): Operand A is presented during [0, 15] ms, followed by a silent working-memory delay in [15, 30] ms, Operand B in [30, 45] ms, and Motor/Output readout in [45, 60] ms.
  • Arithmetic Schedule (add_3bit, sub_3bit, mod_add): Operands A and B are presented concurrently during [0, 30] ms, followed by readout integration during [30, 60] ms.

4.3 Kenyon-Cell Expansion, Three-Factor R-STDP, and Dale's Law

Mirroring the sparse associative expansion of the Drosophila Mushroom Body, early-window and readout-window firing rates from sampled Mushroom Body (mb_idx) and Central Complex (cx_idx) neurons—concatenated with raw Motor/Output pool counts—are projected through a fixed random matrix WKC into 1,024 rectified Kenyon-cell features in the 0–100 model:

hraw = [ rearly(MB, CX),   rreadout(MB, CX),   cmotor ],    hKC = max(0, WKC hraw)
(4)

Plastic synapses targeting Mushroom Body and Motor/Output populations maintain decaying pre-synaptic (xi) and post-synaptic (yj) traces alongside per-synapse eligibility traces eij(t) with decay λe = 0.95, potentiation A+ = 1.0, and depression A− = 0.5. At trial completion, scalar dopamine reward r ∈ {+1, −1} centered by an exponential moving baseline r̄ ← 0.95 r̄ + 0.05 r gates synaptic updates:

eij(t + 1) = λe eij(t) + A+ xi(t) sj(t) − A− si(t) yj(t),    ΔWij = η (r − r̄) eij(T)
(5)

After every synaptic update, Dale's Law is enforced strictly: excitatory cholinergic weights are clamped to [0, wmax] and inhibitory GABA/glutamatergic weights to [−wmax, 0], with wmax = 5.0. During interactive user punishment (r = −1), TrainingConfig amplifies negative updates via neg_penalty_scale = 2.0, progressive mistake scaling (mistake_scale_step = 0.75 up to 4.0), and a decaying state-dependent taboo penalty (taboo_penalty = 5.0, taboo_decay = 0.92) so the network visibly shifts away from punished errors.

4.4 Spiking REINFORCE Baseline and 9-Bit Output Decoding

As a policy-gradient comparison, ReinforceAgent updates readout parameters θ = (Wout, bout) via softmax probabilities πθ(y|x) at temperature 0.5 with learning rate lr_reinforce = 0.03 and entropy coefficient 0.02:

Δθ = ηRL [ (r − r̄) ∇θ log πθ(y|x) + 0.02 ∇θ H(πθ(·|x)) ]
(6)

For delayed_xor (K = 2) and mod_add (K = 7), the predicted integer is the argmax over competing class logits. For 0–100 add_3bit and sub_3bit, the readout decodes 9 competing binary output bits (1 sign bit plus 8 magnitude bits covering [−100, 200]), where each bit is decided from its signed logit and reassembled into a signed integer. Top-4 candidate answers reported in the UI are ranked by bit-Hamming log-likelihood. Table 4 summarizes all biophysical and plasticity hyperparameters.

5. Experimental Design and Scientific Controls

To isolate the contribution of biological wiring topology from generic recurrent dynamics or parameter count, scripts/run_experiments.py and scripts/export_serverless_artifacts.py evaluate four tasks against two structural/algorithmic controls and three lesion protocols:

  • Degree-Preserving Shuffled Connectome: Configuration-model rewiring permutes presynaptic column indices across the CSR matrix while preserving every neuron's exact in-degree, out-degree, and E/I neurotransmitter sign ratio.
  • Matched-Budget PyTorch GRU: A non-spiking recurrent baseline trained with REINFORCE on identical 60 ms input sequences and episode budgets.
  • Targeted Lesion Protocols: Silencing the Central Complex (2,875 neurons), silencing the Mushroom Body (5,608 neurons), and silencing the top 5% highest out-degree hub neurons ranked by torch.bincount(col_indices).

6. Empirical Results and Ablation Analysis

6.1 Hardware Throughput: Local CPU versus Local GPU

Benchmarking the complete 138,639-neuron, 15,091,983-edge CSR graph across 60 ms trials (scripts/benchmark_hardware.py, recorded in artifacts/hardware_benchmark.json) reveals an asymmetric scaling profile typical of irregular sparse graphs. At batch size 1, sparse CSR matrix-vector multiplication (torch.mv) on local_gpu completes a 60 ms trial in 129.40 ms versus 1572.10 ms on local_cpu—a 12.1× speedup achieving 165,568.4 spikes/s within 330.08 MB of GPU memory. At batch sizes 16 and 64, however, torch.sparse.mm suffers from irregular gather contention on GPU (11,886.21 ms and 59,356.44 ms), making batch size 1 the optimal regime for interactive single-episode GPU simulation.

6.2 Working-Memory Controls and Lesion Recovery (Delayed XOR)

In the 10-episode local smoke experiment on delayed_xor (artifacts/experiments/summary.json), the real FlyWire connectome trained with R-STDP reached 70.0% held-out accuracy (955.6 mean spikes/trial), outperforming both spiking REINFORCE (60.0%, 1030.5 spikes) and the matched PyTorch GRU (40.0%, 0.0 spikes). The degree-preserving shuffled connectome also reached 70.0% (958.6 spikes) on this binary task, indicating that degree distribution alone supports 2-class delay separation when readout plasticity is active.

Targeted ablation confirmed functional specialization: silencing the Central Complex immediately collapsed held-out accuracy to 0.0% (951.0 spikes/trial) by disrupting midline working-memory propagation. Continuing R-STDP training post-lesion drove compensatory reweighting across alternative Lateral Horn and Mushroom Body pathways, recovering held-out accuracy to 100.0% (938.0 spikes/trial). In contrast, silencing the top 5% highest-degree hub neurons extinguished global recurrent activity completely (0.0 mean spikes).

7. Production Serverless Architecture and Live Interface

7.1 Vercel Serverless Constraints and Pure-NumPy CSR Kernel

Deploying an interactive connectome application on Vercel Serverless Functions requires keeping the unzipped Python bundle strictly below 250 MB, which precludes PyTorch and CUDA binaries. Accordingly, scripts/export_serverless_artifacts.py extracts the induced 3,000-landmark dorsal subnetwork containing 61,453 directed edges and exports it alongside trained 1,024-Kenyon-cell weights into artifacts/serverless/subnetwork.npz (4.13 MB) and layout_and_summary.json (290.5 KB).

At runtime, api/index.py loads these CSR arrays into ServerlessBrainEngine using only fastapi, numpy, scipy, and pydantic, executing sparse synaptic propagation via np.bincount(W_indices, weights=W_data * active_spikes, minlength=n). 9. Limitations and Conclusion

This study models neurons as single-compartment Leaky Integrate-and-Fire units without dendritic nonlinearities, voltage-gated ion channel dynamics, or multi-layer surrogate-gradient backpropagation across the 138,639-neuron graph. In addition, the live Vercel serverless deployment executes a 3,000-landmark induced dorsal subnetwork rather than the complete 15.09M-edge GPU connectome.

Within these explicit scientific boundaries, the project provides a reproducible, transparent testbed for whole-brain spiking computation: a real Drosophila connectome accelerated 12.1× on GPU can acquire small discrete associations via dopamine-modulated R-STDP and recover from targeted Central Complex lesions through plastic rerouting, while clearly delineating where biological reservoir computing diverges from exact multi-bit digital arithmetic.
